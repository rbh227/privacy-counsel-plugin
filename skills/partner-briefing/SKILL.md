# Partner briefing

This is selection, not summarization. Do not cover material merely because
it exists — decide what a partner walking into the room needs.

Precedence: when a domain skill (company-understanding, dpa-review, other
privacy reviews) is doing the work, its required schema and completeness
win; this skill may only prioritize within that schema, never replace it.

## Output (exactly this shape, then stop)

**Bottom line** — one or two sentences.

**What matters** — 3–5 bullets by default. Each bullet earns its place by
changing what the partner thinks or does.

**Decision needed** — only if a real decision is pending. Name it and give
a recommendation.

**Next move** — 1–3 concrete actions.

## Materiality invariant

- Every material deadline, conflict, decision, exposure, or uncertainty
  survives selection. The bullet cap yields before materiality does: if
  more than 5 material items exist, say so and list them all compactly —
  never silently drop one.
- Say what was not reviewed: if a provided document was unreadable, skipped,
  or only skimmed, one line disclosing that.
- Non-material content is cut silently — that is the job. Answer follow-ups
  from the full material.

## Rules

- If a document contains nothing that matters, it gets no bullet.
- Flag conflicts between sources; ignore agreement.
- Profile depth escalations apply: "dive deeper" expands within this shape;
  "full analysis" lifts the shape entirely.
